# 中药材种植参考建议

## Overview

三条主线：**地区 → 2-3 个候选品种**，**药材 → 种植参考建议**（同时给地区则判该地适不宜种这味），**不给地区 → 全国当期 top 3 方向性候选**。

本地底座直接复用 `/daodi` 的道地药材库（31 个省级区域 / 524 条，见 `../daodi/references/daodi-yaocai.md`），**不另建库、不复制数据**；本 skill 的脚本只做候选排序与竞争格局聚合。道地库回答不了的价格、面积、生育期、连作、成本、合规，一律走 `references/dimensions.md` 的 17 个维度联网核实。

把本 SKILL.md 所在目录记为 `$SKILL_DIR`。不要整份读入道地库文件，一律走脚本。

## 0 `-h` / `--help`

参数只有 `-h`、`--help` 或 `帮助` 时，不查库、不联网，把下面内容原样输出到回复正文后结束：

```
用法: /zhongzhi <地区名 | 药材名 | 地区+药材 | --pick> [选项]

四种输入
  地区名（省 / 大区 / 市 / 县）    → 2-3 个候选栽培品种 + 每个品种的取舍理由
  药材名（正名 / 道地产品习用名）  → 种植参考建议（六段）
  药材 + 地区（黄精 湖北、文山三七）→ 判该地区有无这道地记录、本区位次；无记录按引种风险输出
  --pick（不给地区，问「今年种什么」）→ 全国当期榜初筛，先给排除清单再给 3 个方向性候选

选项
  --top=<N>   地区模式本地候选看前 N 味（默认 8，最终只推荐 2-3 味）
  --pick=<N>  全国当期榜看前 N 味（默认 15，最终收敛到 3）
  --fast      只查最小必核集（生育期 / 价格分位 / 在田面积 / 保本价 / 耕地合规）
  -h, --help  本帮助

例
  /zhongzhi 湖北          /zhongzhi 黄精          /zhongzhi 黄精 湖北
  /zhongzhi 文山 --top=6  /zhongzhi --pick        /zhongzhi --pick=20 --fast

说明
  分析维度 17 条，见 references/dimensions.md，分四层：
    能不能种活（基原种质 / 气候 / 土壤 / 连作）
    种不种得成（技术规程 / 生育期 / 病虫害 / 种苗）
    卖不卖得动（价格周期 / 供给管道 / 社会库存 / 需求 / 成本）
    允不允许（耕地用途管制 / 濒危合规 / 质量检测 / 政策补贴）
  判定用绿 / 黄 / 红三档，红灯一票否决（用途管制、无种源、无规程、算不出保本价）。
  本地库只含产地与性状，不含价格面积；结论必带数据截止日与来源，未核实项标（待核）。
  每份报告自带「引用数据清单」：逐条对上结论、标来源层级与「原文/索引级/待核」，并列出未取到与未检索的维度。
  只有搜索标题与摘要（索引级）的来源不得支撑绿灯判定；数字型结论无原文时改为区间或待核。
  未知选项一律回帮助，不当成关键词凑结果。
  只给决策参考：不承诺收益、不承诺回收、不作投资建议，用药与治疗问题请遵医嘱。
```

## 1 参数解析与分支判定

先把输入拆成「模式参数」与「修饰选项」，再进对应分支。用户通常不给 flag，直接给词，所以下面第一张表是识别规则。

| 输入 | 解析为 | 进哪条 |
| --- | --- | --- |
| 省 / 大区 / 市县名（湖北、西南、文山、罗田、安国） | `--region` | A |
| 药材正名或道地产品习用名（黄精、三七、怀牛膝、中宁枸杞） | `--name` | B |
| 两个都给（`黄精 湖北`、`文山三七`、`想在罗田种茯苓`） | `--name` + `--region` | B 的组合模式（见第 3 节末） |
| 「今年种什么 / 当期 / 推荐前 3 个」且没给地区 | `--pick` | C |
| 既没地区也没品种，也没要全国方向 | — | 先问四件事（见本节末） |

| 修饰选项 | 作用 | 默认 |
| --- | --- | --- |
| `--top=<N>` | A 模式本地候选看前 N 味（最终仍只推 2-3 味） | 8 |
| `--pick=<N>` | C 模式全国榜看前 N 味（最终收敛到 3） | 15 |
| `--fast` | 只查最小必核六条（A2 表），来不及过 17 维时用 | 关 |
| `--json`、`--score=off` | 透传给脚本，取结构化数据或去掉权重时用 | 关 |

三条解析规则：

1. **地区与药材拿不准时，先按药材解析**：跑 `--name`，`exit=3` 再按地区跑 `--region`；两次都 `exit=3` 才回头问用户。不要凭印象猜省份（`拉萨` 不在库内，但 `西藏` 在，这种情况应当问清而不是自动套省）。
2. **未知选项不猜**：出现拼错的 flag 或不认识的参数，输出第 0 节帮助并点明是哪一项不认识，绝不把它当自由关键词塞进查询凑结果。
3. **`--pick` 与地区、药材互斥**：同时出现时按措辞定优先级——提到具体省县或具体药材就走 A/B，只有「今年 / 当期 / 全国 / 随便推荐」这类无地区措辞才走 C。

四件不齐就别往下算：地区（到县）、土地性质（耕地 / 林地 / 草地，是否永久基本农田）、可用资金与可接受回本年限、有无收购渠道。

## 2 分支 A：地区 → 2-3 个品种

### A1 本地候选排序

```bash
node $SKILL_DIR/scripts/zhongzhi_scan.cjs --region=<地区> [--top=8]
```

脚本自动分流：先按省/大区匹配（`-r`），未命中再按市县级产区反查（`-c`）并附同省参考品种，`本区` 列标 `命中` 的行才是该地区直接道地记录。`exit=3` 表示库内无此地区（脚本会提示先确认它属哪个省，不要凭印象套省份）；`exit=2` 是参数错误，不能当无结果。

排序分只由本地可确证的信号构成（地标/GAP 认证、经典药群归属、跨省产区集中度、本区县数），**只用于决定核实的先后顺序，不是推荐度**。

### A2 挑 3-5 味联网核实

从候选里挑 3-5 味（含 `本区命中` 的高分品种，也留一味低竞争或差异化品种），逐味过 `references/dimensions.md`。全过 17 条成本高，时间不足时至少查这几条：

| 必查 | 为什么是它 |
| --- | --- |
| 6 生育期与采收年限 | 决定回本年限与供给滞后，权重最高 |
| 9 价格分位与近 12 个月方向 | 判断周期位置，用相对量不用绝对价 |
| 10 在田面积（不是规划面积） | 未来 1-N 年的潜在供给 |
| 13 亩投入 ÷ 亩产干品 = 保本价 | 算不出来就不出建议 |
| 14 耕地/林地用途管制 | 唯一能直接否决的合规项 |
| 4 连作障碍 | 老药区常已无新地，实际可种面积远小于气候适宜面积 |

`--fast` 表示只查上表六条；不带 `--fast` 时 17 条逐条给档。

### A3 输出 2-3 味（不许只报冠军）

- **稳妥位 1-2 味**：本区道地 `命中` + 绿档维度多 + 有成熟规程与明确收购方。
- **进攻位至多 1 味**：周期中低位、跨省产区集中（别人不好复制）、或有本地品牌/地标可依托。
- 必须写**为什么淘汰**排在它前面的高分候选（例如：认证多但已连涨 3 年、忌连作且当地无新地、种苗被外地垄断）。
- 候选库覆盖不足时（`本区命中` ≤2 味）：明确说本地库对该地区记录有限，联网补齐当地区域公用品牌与主栽品种清单；可提示用户「要把结果补进道地库就用 /daodi」。

## 3 分支 B：药材 → 种植参考建议

```bash
node $SKILL_DIR/scripts/zhongzhi_scan.cjs --name=<药材>
```

拿到全国道地省数、各省道地商品名与产区、品质特征、认证与药群归属、竞争结构判定。`exit=3` 时先联网确认它是否被收载为道地，不要改字凑库内条目。

然后按用户所在地（没说就问；用户只要全国方向就转第 4 节分支 C）出建议，六段：

1. **产区格局**：主产区在哪、集中度如何、外地货的历史认可度与检测指标差异。
2. **本底适配**（维度 1-4）：气候、土壤、地形、连作与地块历史逐项给绿/黄/红，指明与主产区的关键差异（海拔、积温、极端低温、降雨集中期）。
3. **农艺可行性**（维度 5-8）：规程出处、有无当地大田案例、生育期与采收年限、种苗来源与价格。
4. **市场与周期**（维度 9-13）：价格分位数与近 12 个月方向、在田面积与供给管道、库存代理指标、需求结构、保本价区间。**必须写明当前处在周期哪一段，以及扩种后自己会不会成为供给峰值的一部分。**
5. **合规红线**（维度 14-17）：土地性质、濒危与许可、质量要求、补贴依赖度。
6. **风险与否决项**：把红灯列在最前；给出「先小面积试种 N 年再扩」这类可逆路径，而不是直接建议规模种植。

### 3.1 同时给了地区 → 组合模式

```bash
node $SKILL_DIR/scripts/zhongzhi_scan.cjs --name=<药材> --region=<地区>
```

多输出三件事：该地区有无道地记录、本省在全国的位次（按产区点位数）、无记录时的引种风险结论。按结果定调：

| 组合结果 | 六段里怎么写 |
| --- | --- |
| 命中且位次第 1 | 主产区本身，第 4 段市场按「竞争看成本与渠道」写，别写差异化产区牌 |
| 命中但位次靠后 | 必须回答「凭什么卖得掉」——地标、加工能力、就近收购，答不上就是黄档 |
| 未命中 | 属引种到非道地产区：第 2 段本底与第 5 段合规直接决定成不成；第 4 段写明「外地货认可度未验证」，先落实收购方再谈面积 |

位次口径：产区点位数是**记录密度**，不是种植面积，只用于排相对位置。

## 4 分支 C：不给地区的当期全国推荐（top 3）

用户没给地区、只问「今年种什么 / 推荐前 3 个」时走这条。**没有地区只能给方向，不能给定稿推荐**——道地性、收购方、烘干加工能力都是县级尺度的事，回复里必须写明这一条并邀请 `/zhongzhi <地区>` 收敛。

### C1 拉全国榜 + 判大盘方向

```bash
node $SKILL_DIR/scripts/zhongzhi_scan.cjs --pick=15
```

榜的目标与分省候选榜**不同**：奖励品牌壁垒（地标/药群）与产区集中（别人不好复制），惩罚全国都在产的同质品种。分数只决定核实顺序。

同时判断当期大盘是涨是跌（安国/亳州/普宁指数年度报告、权威行情报道，至少两源）。**下行期与上行期的选品逻辑相反**：下行期最大的收益来自不种别人正在扩的品种，而不是找到下一个领涨品种。

### C2 先出排除清单（这一段不能省）

| 排除规则 | 理由 |
| --- | --- |
| 上一轮领涨 **且** 采挖年限 ≥3 年 | 高价 + 补贴驱动的扩种面积正在集中采挖，新进入等于承接供给峰值 |
| 库内备注或公开报道显示单一省/县已达**十万亩级**面积 | 一个县的面积就能压平该品种的价格弹性（例：库内已记录崇阳黄精 2025 年 16.07 万亩） |
| 本省无道地记录、无收购方、无加工能力 | 没有地区时这类品种风险不可估 |
| 只在涨期有需求、跌期无刚性用途 | 缺药用以外的需求增量（康养、饮片、出口、提取物） |

排除清单要实名、给依据，不写抽象原则。

### C3 再给 3 个方向性候选

每个候选必须挂四件事：**进入门槛**（凭什么是你，差异化来源是地标、气候还是渠道）、**退出成本**（当年或一年生可采收优先，多年生在下行期等于锁死资金 3 年以上）、**需求增量来源**（药用以外的部分）、**本轮未核实项**（标 `（待核）`）。

- 三个候选**必须来自不同需求结构**（例如一个药食同源/康养、一个饮片与提取物原料、一个出口或化工原料），否则等于让用户同涨同跌。
- 榜上排第一的不是答案：它是"本地信号最强"，不是"现在该种"。周期位置靠 C1 的实时判断。
- 不给价格、面积、单产、收益的具体数字，除非当场查到并写来源；查不到就写「未查到」。

## 5 实时信息检索纪律

- 每个维度**至少两轮**检索；一条结论要**两个独立来源一致**才写成确定事实，否则句末标 `（待核）`。
- 来源优先级见 `references/dimensions.md` 末表：主管部门公布目录 > 药典/国标/行标/地标 > 流通与仓储统计 > 上市公司年报 > 市场价格指数 > 产地报道。
- **绝不编造价格、面积、单产、成本数字**。查不到就写「未查到」并列出需要用户补的数据。
- **区分正文级与索引级**：抓到页面正文才算「原文」；只有搜索结果的标题与摘要时一律标「索引级」。**索引级引用不得支撑任何绿灯判定**，只能作方向线索，相关维度最高只能给黄档。
- 单条引用格式：`[序号] <发布机构或媒体>｜<标题/口径>｜<URL 或域名>｜发布 <YYYY-MM-DD>｜原文 或 索引`。回复开头固定一行 `数据截止：<YYYY-MM-DD>（本地道地库截止 2026-09-21）`。
- **空缺必须显式**：清单末尾要列「检索失败项」（结果跑偏、无结果、抓取被限）与「未检索维度」（本轮根本没查的），宁可写「未取到」，不许沉默跳过 —— 读者要能分辨哪些结论有数据、哪些只有推理。
- 社会库存没有权威公开统计（中药材无期货品种、无公开仓单），只用代理指标：年报存货与周转天数、产地收购价与批发价价差、市场到货量与仓储紧俏度、HS 1211 进口。
- 道地库中标 `（存核）` 的条目，引用时如实带上这一限定；本地库属「库内已核实」，与实时检索分开编号（前缀 `库-`）。

### 引用数据清单（A/B/C 三分支都必须带，不可省）

规则：

- `层级` 用 `references/dimensions.md` 末表的 1-8 档；`取到的是` 只允许填 **原文 / 索引级 / 待核** 三种。
- 报告里每条实质结论都要能在表里找到对应行；找不到对应行的，要么删掉，要么改写成「推断」并说明推断依据。
- **数字型结论（价格、面积、单产、成本、收益）若只有索引级来源，必须改写成区间或降为待核**，不许以确定口吻写。
- `未取到` 与 `未检索` 两行必填 —— 让读者一眼分清哪些结论有数据、哪些是推理。

## 回答规范

- **红灯优先于收益**：用途管制不过、无种源、无技术规程、算不出保本价 → 直接给「暂不建议」，不因为行情好而绕开。
- 结论一律给区间与三档判定，不给绝对价、不给具体收益承诺、不写「包回收」「稳赚」类表述。
- 提醒反身性：种植建议被采纳后会改变供给，从而削弱建议本身的成立条件；给出试种→扩产的分期路径优于一次到位。
- 涉及补贴驱动的扩种，明确指出补贴退坡是主要下行风险。
- 动物药、濒危植物来源（麝香、鹿茸、石斛、川贝母、重楼等）必须提示核对合法来源、野生/栽培属性与许可手续。
- 只回答种植与产地事实，不作诊疗、用量、药材选购建议；涉及用药与治疗问题提示遵医嘱。
- 每份报告必须带**引用数据清单**（第 6 节末模板）：逐条对上结论、标层级与「原文 / 索引级 / 待核」，并写出 `未取到` 与 `未检索`；只到标题摘要层的引用，相关判定最高给黄档。
- 结尾固定列五项：`结论`、`引用数据清单`、`关键待核实项`、`需要用户提供`（土地性质/面积/资金/渠道）、`数据截止`。
