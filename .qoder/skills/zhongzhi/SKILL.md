# 中药材种植参考建议

## Overview

两条主线：**地区 → 2-3 个候选品种**，**药材 → 种植参考建议**。

本地底座直接复用 `/daodi` 的道地药材库（31 个省级区域 / 524 条，见 `../daodi/references/daodi-yaocai.md`），**不另建库、不复制数据**；本 skill 的脚本只做候选排序与竞争格局聚合。道地库回答不了的价格、面积、生育期、连作、成本、合规，一律走 `references/dimensions.md` 的 17 个维度联网核实。

把本 SKILL.md 所在目录记为 `$SKILL_DIR`。不要整份读入道地库文件，一律走脚本。

## 0 `-h` / `--help`

参数只有 `-h`、`--help` 或 `帮助` 时，不查库、不联网，把下面内容原样输出到回复正文后结束：

```
用法: /zhongzhi <地区名 | 药材名> [选项]

两种输入
  地区名（省 / 大区 / 市 / 县）→ 输出 2-3 个候选栽培品种 + 每个品种的取舍理由
  药材名（正名 / 道地产品习用名）→ 输出种植参考建议

选项
  --top=<N>   地区模式本地候选看前 N 味（默认 8，最终只推荐 2-3 味）
  --fast      只查最小必核集（生育期 / 价格分位 / 在田面积 / 保本价 / 耕地合规）
  -h, --help  本帮助

说明
  分析维度 17 条，见 references/dimensions.md，分四层：
    能不能种活（基原种质 / 气候 / 土壤 / 连作）
    种不种得成（技术规程 / 生育期 / 病虫害 / 种苗）
    卖不卖得动（价格周期 / 供给管道 / 社会库存 / 需求 / 成本）
    允不允许（耕地用途管制 / 濒危合规 / 质量检测 / 政策补贴）
  判定用绿 / 黄 / 红三档，红灯一票否决（用途管制、无种源、无规程、算不出保本价）。
  本地库只含产地与性状，不含价格面积；结论必带数据截止日与来源，未核实项标（待核）。
  只给决策参考：不承诺收益、不承诺回收、不作投资建议，用药与治疗问题请遵医嘱。
```

## 1 判分支

| 输入形态 | 分支 | 动作 |
| --- | --- | --- |
| 省名、大区名、市县名（湖北 / 西南 / 文山 / 罗田 / 安国） | A | 出 2-3 个品种 |
| 药材名（三七 / 牛膝 / 怀牛膝 / 中宁枸杞） | B | 出种植参考建议 |
| 既是产区又是药材（文山三七、湖北茯苓） | B 为主 | 按 B 走，并把「引种到非道地产区」的差异作为重点风险 |
| 只说「想种药材」没给地区也没给品种 | 先问 | 问清地区、土地性质（耕地/林地/草地）、可用资金与回本年限、有无销售渠道，四件不齐就别往下算 |

## 2 分支 A：地区 → 2-3 个品种

### A1 本地候选排序

```bash
node $SKILL_DIR/scripts/zhongzhi_scan.cjs --region=<地区> [--top=8]
```

脚本自动分流：先按省/大区匹配（`-r`），未命中再按市县级产区反查（`-c`）并附同省参考品种，`本区` 列标 `命中` 的行才是该地区直接道地记录。`exit=3` 表示库内无此地区（脚本会提示先确认它属哪个省，不要凭印象套省份）；`exit=2` 是参数错误，不能当无结果。

排序分只由本地可确证的信号构成（地标/GAP 认证、经典药群归属、跨省产区集中度、本区县数），**只用于决定核实的先后顺序，不是推荐度**。

### A2 挑 3-5 味联网核实

从候选里挑 3-5 味（含 `本区命中` 的高分品种，也留一味低竞争或差异化品种），逐味过 `references/dimensions.md`。全过 17 条成本高，时间不足时至少查这几条：

| 必查 | 为什么是它 |
| --- | --- |
| 6 生育期与采收年限 | 决定回本年限与供给滞后，权重最高 |
| 9 价格分位与近 12 个月方向 | 判断周期位置，用相对量不用绝对价 |
| 10 在田面积（不是规划面积） | 未来 1-N 年的潜在供给 |
| 13 亩投入 ÷ 亩产干品 = 保本价 | 算不出来就不出建议 |
| 14 耕地/林地用途管制 | 唯一能直接否决的合规项 |
| 4 连作障碍 | 老药区常已无新地，实际可种面积远小于气候适宜面积 |

`--fast` 表示只查上表六条；不带 `--fast` 时 17 条逐条给档。

### A3 输出 2-3 味（不许只报冠军）

- **稳妥位 1-2 味**：本区道地 `命中` + 绿档维度多 + 有成熟规程与明确收购方。
- **进攻位至多 1 味**：周期中低位、跨省产区集中（别人不好复制）、或有本地品牌/地标可依托。
- 必须写**为什么淘汰**排在它前面的高分候选（例如：认证多但已连涨 3 年、忌连作且当地无新地、种苗被外地垄断）。
- 候选库覆盖不足时（`本区命中` ≤2 味）：明确说本地库对该地区记录有限，联网补齐当地区域公用品牌与主栽品种清单；可提示用户「要把结果补进道地库就用 /daodi」。

## 3 分支 B：药材 → 种植参考建议

```bash
node $SKILL_DIR/scripts/zhongzhi_scan.cjs --name=<药材>
```

拿到全国道地省数、各省道地商品名与产区、品质特征、认证与药群归属、竞争结构判定。`exit=3` 时先联网确认它是否被收载为道地，不要改字凑库内条目。

然后按用户所在地（没说就问）出建议，六段：

1. **产区格局**：主产区在哪、集中度如何、外地货的历史认可度与检测指标差异。
2. **本底适配**（维度 1-4）：气候、土壤、地形、连作与地块历史逐项给绿/黄/红，指明与主产区的关键差异（海拔、积温、极端低温、降雨集中期）。
3. **农艺可行性**（维度 5-8）：规程出处、有无当地大田案例、生育期与采收年限、种苗来源与价格。
4. **市场与周期**（维度 9-13）：价格分位数与近 12 个月方向、在田面积与供给管道、库存代理指标、需求结构、保本价区间。**必须写明当前处在周期哪一段，以及扩种后自己会不会成为供给峰值的一部分。**
5. **合规红线**（维度 14-17）：土地性质、濒危与许可、质量要求、补贴依赖度。
6. **风险与否决项**：把红灯列在最前；给出「先小面积试种 N 年再扩」这类可逆路径，而不是直接建议规模种植。

## 4 实时信息检索纪律

- 每个维度**至少两轮**检索；一条结论要**两个独立来源一致**才写成确定事实，否则句末标 `（待核）`。
- 来源优先级见 `references/dimensions.md` 末表：主管部门公布目录 > 药典/国标/行标/地标 > 流通与仓储统计 > 上市公司年报 > 市场价格指数 > 产地报道。
- **绝不编造价格、面积、单产、成本数字**。查不到就写「未查到」并列出需要用户补的数据。
- 引用格式：`来源：<机构/媒体> · 检索于 <YYYY-MM-DD>`。回复开头给一行 `数据截止：<YYYY-MM-DD>（本地道地库截止 2026-09-21）`。
- 社会库存没有权威公开统计（中药材无期货品种、无公开仓单），只用代理指标：年报存货与周转天数、产地收购价与批发价价差、市场到货量与仓储紧俏度、HS 1211 进口。
- 道地库中标 `（存核）` 的条目，引用时如实带上这一限定。

## 回答规范

- **红灯优先于收益**：用途管制不过、无种源、无技术规程、算不出保本价 → 直接给「暂不建议」，不因为行情好而绕开。
- 结论一律给区间与三档判定，不给绝对价、不给具体收益承诺、不写「包回收」「稳赚」类表述。
- 提醒反身性：种植建议被采纳后会改变供给，从而削弱建议本身的成立条件；给出试种→扩产的分期路径优于一次到位。
- 涉及补贴驱动的扩种，明确指出补贴退坡是主要下行风险。
- 动物药、濒危植物来源（麝香、鹿茸、石斛、川贝母、重楼等）必须提示核对合法来源、野生/栽培属性与许可手续。
- 只回答种植与产地事实，不作诊疗、用量、药材选购建议；涉及用药与治疗问题提示遵医嘱。
- 结尾固定列四项：`结论`、`关键待核实项`、`需要用户提供`（土地性质/面积/资金/渠道）、`数据截止`。
