# 道地药材分布查询

## Overview

以 `references/daodi-yaocai.md`（31 个省级区域、521 条已联网核实的道地药材记录）为数据底座，先查本地库；查不到再联网核实并把结果回写进库，使库随使用增长。

把本 SKILL.md 所在目录记为 `$SKILL_DIR`，脚本和数据都在它下面。不要整份读入 `daodi-yaocai.md`（约 800 行），一律走查询脚本。

## 0 `-h` / `--help`

参数只有 `-h`、`--help` 或 `帮助` 时，不查库、不联网，把下面内容原样输出到回复正文后结束（代码块注入上下文不等于已展示给用户）：


## 1 查询（默认动作）

```bash
node $SKILL_DIR/scripts/daodi_query.cjs [选项] [关键词...]
node $SKILL_DIR/scripts/daodi_query.cjs --list          # 库覆盖概览
node $SKILL_DIR/scripts/daodi_query.cjs -h              # 参数帮助
```

四个维度参数，同类多值取并集（逗号分隔），不同类之间取交集：

| 参数 | 作用 | 命中字段 |
| --- | --- | --- |
| `-n` `--name` | 指定药材名，正名或道地产品习用名皆可 | 药材 + 道地产品别名 |
| `-r` `--region` | 指定区域，大区名（华北/东北/华东/华中/华南/西南/西北）或省名（`云南`、`云南省`） | 省级归属 |
| `-c` `--county` | 反查市县级产区出哪些道地药材 | 道地产区 |
| `-g` `--group` | 经典药群 | 备注 |
| 位置关键词 | 不限字段的自由词，多词须同时命中 | 全字段 |

其余：`--by=name|product|region|feature|note|all`（限定位置关键词字段）、`--province=<省>`（旧写法，等价 `-r`）、`--limit=<N>`、`--json`、`--list`、`-h`。

把用户口语映射到参数：

| 用户问法 | 参数 |
| --- | --- |
| 三七哪里的道地 | `-n 三七` |
| 云南的三七怎么样 | `-n 三七 -r 云南` |
| 党参和黄芪各产地哪个好 | `-n 党参,黄芪`（并集后按省对比） |
| 湖北有哪些道地药材 | `-r 湖北` |
| 西南道地药材有多少 | `-r 西南 --list` |
| 焦作温县都出什么 | `-c 焦作` 或 `-c 温县` |
| 浙八味都有哪几味 | `-g 浙八味` |
| 怀牛膝是什么药材 | `-n 怀牛膝`（别名自动对应正名牛膝） |

要点：

- 维度参数比位置关键词精确：能判定出「药材 + 区域」两件事就用 `-n` + `-r`，不要把两个词塞进位置关键词（后者要求两词同时命中同一行的任意字段）。
- 单独一个省名或大区名作位置关键词（`湖北`、`西南`）会自动转成 `-r` 过滤，无需改写。
- 命中首行 `查询:` 回显生效条件，据此确认没查错维度；`exit=0` 有命中，`exit=3` 且首行 `NOT_FOUND:` 表示本地库没有 → 转第 2 步，`exit=2` 是参数错误（拼错的选项、缺取值、不认识的区域名、非法 `--by` 值），不能当成无结果。
- 匹配会自动拆「道地产品」列的别名，因此用习用名（怀牛膝、中宁枸杞、象贝）和用药典正名（牛膝、枸杞子、浙贝母）都能命中。
- 输出里提示的「存核」条目，回答时要如实带上这一限定，不要转述成已确证。
- 想读原始表格片段时用 grep 定位，不要全文 Read：`grep -n '^## 云南' -A 25 $SKILL_DIR/references/daodi-yaocai.md`。

## 2 本地无结果 → 联网核实并回写

1. `WebSearch` 至少两轮（如 `〈药材〉 道地药材 产区 名录`、`〈药材〉 地理标志 保护产品`），必要时 `WebFetch` 取正文。优先级：省级中医药/农业农村主管部门公布的道地药材目录 > 国家知识产权局地理标志公告 > 《中国道地药材》类专著与行业标准 > 权威媒体/产地政府报道。
2. **两个以上独立来源一致**才写「道地产区」到市县级；只有单一来源、或产地只到省级、或地理标志名称未确认，就在备注末尾加 `（存核）`。查不到就回答查不到，绝不编造产地或地标名。
3. 按库格式插到对应 `## 省份` 小节的表格末尾（一行一条，单元格内不得出现 `|`；该省没有小节就按文件内既有的大区间顺序新建 `## 省份` + 表格 + `> 来源：` 行）：

   ```
   | 药材 | 道地产品 | 道地产区 | 品质特征 | 备注 |
   ```

   列语义：药材=《中国药典》正名；道地产品=当地习用名/地理标志产品名（与药材名相同就重复写）；道地产区=市县级主产地、顿号分隔；品质特征=形色质气味或含量指标，10-25 字；备注=经典药群、地标/GAP、出处简称。

   产区写法用「市名+县名」粘连（`咸宁崇阳`、`咸宁通城`），一个市多个县写成 `咸宁（通城、崇阳、赤壁、咸安）`，这样 `-c 咸宁` 与 `-c 通城` 都能命中。库里存量行有只写县名的（如 `通城`），市级查询会漏，遇到时顺手补上市名，不要新增只写县名的行。
4. 刷新头部统计与经典药群索引（保留分省正文不动）：

   ```bash
   node $SKILL_DIR/scripts/rebuild_db.cjs --reindex
   ```

   输出的条数应比回写前 +1，且幂等（重跑条数不变）。然后重跑第 1 步确认关键词能命中，再回答用户。

## 3 全量重建库

要求重做数据（换数据源、补省份、大版本更新）时：

1. `mkdir -p $SKILL_DIR/references/_parts`，按大区派并行 research subagent（每个负责 5-7 个省），每个 agent 的指令必须包含：联网核实要求（来源优先级、单源标 `（存核）`、禁止编造）、负责的省份清单、输出文件路径 `references/_parts/<片区>.md`、以及上面那份 5 列表格格式约定（`## 省份` 标题不带「省/市/自治区」后缀、每省表格后跟一行 `> 来源：`、单元格内无 `|`）。
2. 大区划分（与库内省份顺序一致）：华北 京津冀晋蒙；东北 辽吉黑；华东 沪苏浙皖闽赣鲁；华中 豫鄂湘；华南 粤桂琼；西南 渝川黔滇藏；西北 陕甘青宁新。
3. 合并 + 生成索引：

   ```bash
   node $SKILL_DIR/scripts/rebuild_db.cjs --from-parts
   ```

4. 验收（四项都要过）：

   ```bash
   grep -c '^## ' $SKILL_DIR/references/daodi-yaocai.md      # 32 = 31 省 + 1 索引节
   grep -c '^> 来源' $SKILL_DIR/references/daodi-yaocai.md   # 31
   node $SKILL_DIR/scripts/rebuild_db.cjs --reindex          # 输出「异常行 0」，条数符合预期
   node $SKILL_DIR/scripts/daodi_query.cjs 三七              # exit=0 且有命中
   ```

   「异常行」是非 5 列的表格行，这些行查询脚本读不到；不为 0 就逐省排查修正后重跑。

5. 验收通过后删除 `references/_parts/`（正式库已含全部分省正文与来源行，片段是中间产物）。重建会改写整个库文件，动手前先确认工作区干净或提交，以便回退。

## 回答规范

- 先给结论（道地产区 + 道地产品名），再给品质特征和经典药群归属；跨省同名品种要对比着说（如党参：甘肃渭源纹党 / 山西潞党参 / 湖北板桥党参）。
- 每条结论说明依据是「库内已核实」还是「本次联网核实」，含 `（存核）` 的要明说待复核。
- 只陈述产地与性状事实，不作诊疗、用量、选购建议，涉及用药提示遵医嘱。
- 动物药、濒危植物来源（麝香、鹿茸、金钱白花蛇、沉香、肉苁蓉等）要提示核对合法来源与野生/栽培属性。
